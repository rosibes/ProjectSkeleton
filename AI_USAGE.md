AI Usage

Tools Used


Claude Sonnet 4.6 (claude.ai) — chat-based assistance throughout the project


How I Used It

I used Claude as a tutor and code reviewer.

The workflow for every file was:

I asked Claude to help structuring the project and organize the code into files.
Claude explained the project architecture, each concept and purpose of the class before writing any code
Claude wrote an initial version with line-by-line explanations
I asked follow-up questions until I understood each part
We debugged together — I ran the code locally, tried to understand the errors/bugs and reported them back to the chat.

All files were developed with AI assistance throught discussion and code suggestions.
I did not copy-paste code blindly. Every bug we fixed, I tried to understand why it happened before applying the fix.
